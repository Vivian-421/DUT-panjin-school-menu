# DUT Panjin School Menu

大连理工大学盘锦校区食堂菜单

把学校食堂的菜单慢慢整理到一起，方便查价格、找吃的，供选择困难症使用。由于作者是吃什么记什么所以菜单还很不完全，欢迎大家通过提issue、fork后提交pull request修改补充。作者打算菜单完成后做成MCP供喜欢玩AI的同学使用（比如可以问AI今天吃什么好），后续会加入个性化功能，可以让同学们自己记自己的偏好。现在是纯菜单
这里不包括八三，只收录八一、八二、美食广场、第三食堂。八三详见作者的另一个仓库。

## 记录什么

按食堂、窗口整理以下信息：

- 菜品名称与价格
- 规格、加料及打包费用
- 供应时段
- 配菜、位置等客观信息
- 最近核对日期与待确认事项

价格不知道就留空，信息不确定就注明。菜单和价格可能变化，请以窗口当日实际情况为准。

个人口味偏好、私人备注和评价不包含在公开菜单中。

## 一起补充

欢迎通过 **Issue** 提供线索，也可以 **Fork 本仓库后提交 Pull Request**，补充菜单、更新价格或纠正错误。

提交时请尽量写清：

- 哪个食堂、哪个窗口
- 新增或修改的内容
- 信息对应的日期

只知道一部分也可以提交，不必为了填完整而猜测。菜品售罄也不一定代表永久下架，可以注明当天的情况。

所有外部修改均由仓库维护者审核，合并后才会进入正式菜单。
